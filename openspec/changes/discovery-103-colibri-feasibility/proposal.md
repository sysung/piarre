# Proposal

## Why

Refs #103. Disk-streamed expert inference offers useful measurement practices, but upstream memory and throughput claims do not establish compatibility or responsiveness in Piarre. A source-linked eligibility report can identify transferable lessons before an expensive backend trial.

## What Changes

- Propose a no-download Colibri compatibility report tied to exact upstream source, model artifact, backend, template, API, and target-device evidence.
- Evaluate at most two lessons for #94/#102: phase/resource telemetry and admission/stop accounting. Use recorded fixtures to check accounting only.
- Separate documented claims, arithmetic illustrations, mock contracts, and local observations. Preserve unknowns, including total memory, privacy/retention, and server termination.
- Retain the current Docker Qwen route. A client implementation or backend experiment requires a later compatibility and execution decision.

## Capabilities

### New Capabilities

- `local-route-eligibility`: Evidence-linked local inference eligibility reports that distinguish compatibility, resource fit, and responsiveness.

### Modified Capabilities

None. No main specs exist here. These are proposed evaluation requirements, not a new provider commitment.

## Impact

Future offline work belongs under #94's benchmark in open PR #95 and reuses open PR #89's restricted local-client contract. #102 owns whole-task comparison, #90 cache applicability, and #100/#91 the current pilot. No adapter relaxation, model default change, install, download, hardware purchase, runtime start, inference, or spending is authorized. Publish the plan, then wait for human review before Apply. Any live trial needs separately agreed device, artifact, route, resource limits, and budget.
