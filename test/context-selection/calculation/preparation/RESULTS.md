# Neither quantity preparation prototype qualifies

These are exposed development cases with cached direct controls. They cannot establish superiority. The direct controls used two calls per case and completed both numerical questions under parent inspection. Every candidate failure was retained. No prototype is promoted or integrated into product code.

| Prototype | Actual calls | Accepted complete answers |
| --- | ---: | ---: |
| Initial numeric index | 2 | 0/2 |
| Numeric index with shared lexical parsing and code-assigned row IDs | 4 | 0/2 |
| Normalized source quotations | 3 | 0/2 |

The initial index excluded normal hyphenated modifiers and let model-authored row IDs collide with quantity IDs. These preparation/interface defects caused safe rejection. The revised index shares the verified source scanner and code assigns row IDs, removing those failure paths.

The revised indexed version correctly computed38 minutes used and12 remaining for the radio case. Its model audit incorrectly rejected the valid plan with an unsupported criticism. In the filament case it computed the correct7 metres remaining but also claimed authorization from a comparison of available filament. The actual sign-off was absent. The subsequent audit was invalid JSON, so that answer was rejected. Correct arithmetic is not correct policy interpretation.

The normalized-quote version produced an incorrect radio formula and a rejected plan attempting to infer numeric zero from absent sign-off. Its audit rejected the wrong formula, but its own expected arithmetic was also wrong. A correlated self-audit is not independent semantic verification.

Offline checks passed for89 arithmetic/normalization/index cases, plus7 indexed-adapter cases. These establish lexical boundaries, exact arithmetic, status restrictions, references and limits. They do not establish model plan quality. Numeric normalization is tied to an actual original token by exact rational equality. Permission absence does not manufacture a numeric operand. Unit and source meaning remain explicitly unverified.

Each folder is an archived executed variant for reproducibility. Duplicate modules are frozen experiment snapshots, not parallel product APIs. The initial source and interface bugs are preserved in their archive. Existing response logs prevent silent reruns. Subsequent semantic-index work should measure retrieval recall and actual answer quality separately, retaining all original source text and a strong direct-Qwen control.

The initial variant stores its original entrypoint as `screen.mjs.snapshot` to preserve the exact executed bytes, including an unused loop variable rejected by the repository lint. Copy it to `screen.mjs` in a fresh replay directory. Other variant source files are ordinary modules. Recorded source hashes describe the original executed filenames.
