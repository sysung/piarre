# Clear numerical questions reached the plan parser

The independently authored cases were run against unchanged candidate commit917d5fc. The author had not inspected prompts or model outputs. Six calls were consumed: each candidate plan was rejected before an audit call; the direct control used two calls per case. Parent inspection found both direct answers supplied the required numerical results and current permission outcome. Neither candidate delivered an accepted answer.

The radio plan omitted the required qualifiers field and normalized source words such as six/four/two into digit tokens absent from its quotations. The filament plan did the same and invented a numeric zero from an absent sign-off, then tried to express authorization as a numerical comparison. Rejection was correct. The numerical operations themselves were plausible, but the input/meaning contract was not met.

Independent review also identified ambiguity in the original tray question. That finding qualifies its interpretation; it does not rewrite the earlier score or make an omitted calculation a demonstrated success. The new cases explicitly distinguish hypothetical arithmetic from present authorization.

Next hypothesis: a deterministic source-derived index can provide normalized numeric literals and exact provenance, reducing copying and normalization work for the model. Model-selected operations and meaning would remain unverified. The model must never manufacture a numeric authorization value from textual absence. This is a structural source-preparation experiment, not a more permissive parser or a relaxed promotion criterion.
