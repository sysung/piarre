# Triage labels

Use the GitHub label mapped to each role.

| Triage role | GitHub label | Meaning |
|---|---|---|
| `needs-triage` | `needs-triage` | Maintainer review needed |
| `needs-info` | `needs-info` | More information needed |
| `ready-for-agent` | `ready-for-agent` | Ready for agent implementation |
| `ready-for-human` | `ready-for-human` | Ready for human implementation |
| `wontfix` | `wontfix` | Work declined |
